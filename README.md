# 生活 · 记账

个人自用的生活应用：**记账（含统计分析）/ 随笔 / 计划 / 备忘录**，收拢成一条可回看的轨迹。

手机优先，PWA，数据只存在本机浏览器里，不联网、不上传。

## 现在能做什么（v0.10）

| 页面 | 内容 |
| --- | --- |
| **记账** | 顶部「流水 / 统计分析」分段（滚动定位，不切页）、月度卡片（本月收入 / 支出 / 结余，三色 + 当前余额）、「添加一条新记账」、按日分组的流水（每天一行「收 x 支 y」）。流水栏里只有流水，不出现任何统计入口。点一条改，长按一条删（可撤销） |
| **记一笔** | 支出 / 收入两栏；分类九宫格 + 「新增」；二级分类横排；滚轮金额；备注；日期可选到过去任意一天；「轨迹」开关；键盘带「再记」 |
| **统计分析** | 点顶部分段「统计分析」才显示，**与流水互斥**，同一时刻只看到一个：按月 / 按年切换、可前后翻；收入·支出·结余、近 12 个月双色柱状图、收支构成环形图 + 占比排行、支出明细、月度报表。**支出明细点进分类看二级；二级行、报表里某月的收入 / 支出金额，点开都是对应的那批账单** |
| **轨迹** | 按月日倒序的时间轴：大事随笔、每日支出汇总、勾了「轨迹」的单笔 |
| **计划** | 本周必做（**未完成不顺延**，计入达标率）+ 弹性目标（不计入）；同页「备忘」是长期清单 |
| **随笔** | 一行文字 + 「标为大事」开关（标了才进轨迹） |
| **我的**（右上角） | 分类管理、期初余额、导出 / 恢复备份、清空、主题、数据统计 |

## 几处用心的细节

- **分类是自己的**：支出、收入各自一套，可增可改可删；每个一级分类下还有子项目（餐饮 → 早餐/午餐/咖啡/外卖…）。删掉分类不动金额，旧账归为「未分类」。
- **金额是一块机械计数器**：每位数字单独一只滚轮，嵌在内凹的表壳里。变化时低位先转、高位滞后，停止带一点过冲回弹；跨 9 进位是连续滚过去的，不是跳数。删掉一位时，高位是**当场收窄消失**，不会先滚成 0。
- **余额是一条线**：期初余额 + 全部收入 − 全部支出。记一笔当场变。余额默认打成 `¥ ••••`，点右侧眼睛看 5 秒后自动回码；**长按**余额行才改期初（避免误触）。
- **两级分类**：记完的流水显示成「交通 · 打车」。子项目名存的是当时的文字，之后改名不影响旧账。
- **任何数字都能点到底**：统计里从「支出 3,341」→「餐饮 641」→「午餐 320」→ 那 3 笔账单，一路点下去，最后看到的是具体哪天、多少钱、什么备注。月度报表里点某月的收入或支出，同样直接列出当月那批账。
- **液态玻璃**：底下一层缓慢漂移的光雾，顶栏、底栏、键盘、卡片是半透明磨砂面，背后有东西可以折射，所以不是一块纯色板。
- **离线是真的能开**：Service Worker 安装只等首屏那一个文件，图标按需再补，所以第一次打开两三秒就具备离线能力；真断网又没缓存时，给一张说明页而不是白屏。

## 打开方式

线上地址（GitHub Pages，HTTPS，可装主屏）：

```
https://zhangmac.github.io/life/
```

手机浏览器打开 → 分享 → **「添加到主屏幕」**，即成为一个全屏 app（无地址栏、可离线）。

本地也能开：直接双击 `index.html` 就能用；想让 Service Worker 生效（可装主屏、断网可用），则用任意静态服务器指向本目录。

## 数据

默认存在浏览器 IndexedDB，库名 `life`（v2 起多一个 `cats` 存分类）。

**存储有三档，自动降级，任何环境都能打开：**

| 档位 | 条件 | 表现 |
| --- | --- | --- |
| IndexedDB | 正常浏览器 | 完整功能 |
| localStorage | IndexedDB 被拦（Safari 打开本地文件、无痕模式等） | 照样保存，顶部提示条说明 |
| 内存 | 两者都被禁（iframe 沙箱等） | 能用不保存，顶部常驻警告 |

「我的 → 存储方式」随时可看当前档位。降级时数据仍是本机的，只是换了个存法。

- 关页面不丢，清缓存 / 换手机 / iOS 长期不打开都可能丢
- 「我的 → 导出备份」生成 JSON（含流水、分类、期初余额），落到「文件」App；换机器时用「从备份恢复」
- 打开时若超过 14 天没导出，会提示一次
- 从 v0.3 升上来：老库自动补 `cats` 表并写入默认分类，旧账的分类 id 沿用不变，不会失联

**备份不是建议，是这个应用能长期用下去的前提。**

## 导入账单

「我的 → 导入账单」，选 `.csv` 或 `.xlsx`。

- **支持** CSV（UTF-8 / GBK 自动识别）、XLSX（浏览器原生解压，不引第三方库）
- **不支持** `.xls`（OLE2 二进制格式）。用 WPS / Excel 打开后「另存为」xlsx 即可
- 表头按名字认，不认列的位置：只要有「日期」和「金额」两列就能导，`收支类型`、`类别`、`二级分类`、`备注` 有则读、无则空
- **分类自动映射**：`食品餐饮` 会落到你已有的「餐饮」，`出行交通` → 「交通」；对不上的（比如误建的「玉米」）会新建一级分类，导入前在预览里列出来给你看
- **重复导入不会翻倍**：按「日期 + 收支 + 金额 + 备注」建指纹，同一份账单导两次，第二次全部计入「重复」并跳过；同一天真有两笔同额也会各自保留

## 开发

```
index.html          应用本体（单文件：样式 + 逻辑全部内联）
manifest.json       PWA 清单
sw.js               Service Worker（缓存优先 + 后台更新）
icon-*.png          应用图标
SESSION.md          会话文档（下次接手先读这份）
```

改完应用后把 `sw.js` 里的 `VERSION` 加一，旧缓存才会被清掉。
