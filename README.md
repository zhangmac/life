# 生活 · 记录

个人自用的生活记录应用：**记账 / 随笔 / 计划 / 备忘录**，收拢成一条可回看的轨迹。

手机优先，PWA，数据只存在本机浏览器里，不联网、不上传。

## 现在能做什么（v0.3）

| 页面 | 内容 |
| --- | --- |
| **记录** | 「记账 / 随笔」两段。记账：滚轮金额表壳 + 两级分类 + 按需弹出的键盘 + 今日流水；随笔：一行文字 + 「标为大事」开关（标了才进轨迹） |
| **轨迹** | 按月日倒序的时间轴：大事随笔、每日支出汇总、勾了「轨迹」的单笔 |
| **计划** | 本周必做（**未完成不顺延**，计入达标率）+ 弹性目标（不计入） |
| **备忘录** | 长期清单，可勾掉 |
| **我的**（右上角） | 导出 / 恢复备份、清空、主题、数据统计 |

## 几处用心的细节

- **金额是一块机械计数器**：每位数字单独一只滚轮，嵌在内凹的表壳里。变化时低位先转、高位滞后，停止带一点过冲回弹；跨 9 进位是连续滚过去的，不是跳数。
- **键盘不常驻**：点金额表壳才升起来，输完自动收回。正在输入时「记账/随笔」切换会临时收起，把高度让给流水（小屏尤其明显）。
- **两级分类**：一级八类，二级按类展开（餐饮 → 早餐/午餐/咖啡/外卖…），记完的流水显示成「交通 · 打车」。
- **液态玻璃**：底下一层缓慢漂移的光雾，顶栏、底栏、键盘、卡片是半透明磨砂面，背后有东西可以折射，所以不是一块纯色板。
- **离线是真的能开**：Service Worker 安装只等首屏那一个文件，图标按需再补，所以第一次打开两三秒就具备离线能力；真断网又没缓存时，给一张说明页而不是白屏。

## 打开方式

线上地址（GitHub Pages，HTTPS，可装主屏）：

```
https://zhangmac.github.io/life/
```

手机浏览器打开 → 分享 → **「添加到主屏幕」**，即成为一个全屏 app（无地址栏、可离线）。

本地也能开：任意静态服务器指向本目录即可（`file://` 不行，IndexedDB 与 Service Worker 需要 http/https）。

## 数据

存在浏览器 IndexedDB，库名 `life`。

- 关页面不丢，清缓存 / 换手机 / iOS 长期不打开都可能丢
- 「我的 → 导出备份」生成 JSON，落到「文件」App；换机器时用「从备份恢复」
- 打开时若超过 14 天没导出，会提示一次

**备份不是建议，是这个应用能长期用下去的前提。**

## 开发

```
index.html          应用本体（单文件：样式 + 逻辑全部内联）
manifest.json       PWA 清单
sw.js               Service Worker（缓存优先 + 后台更新）
icon-*.png          应用图标
```

改完应用后把 `sw.js` 里的 `VERSION` 加一，旧缓存才会被清掉。
